# Downloaded Original Inputs Manifest

This folder preserves original files copied from `/Users/seokmogu/Downloads`
that were used or referenced during the Park Hyunkeun thesis revision,
advisor-feedback review, formatting check, and defense-presentation work.

## Scope

- `advisor_feedback/` (10 files): advisor comment sources, thesis-title and
  figure/sample images, audio memo, feedback DOCX, Hanyang thesis-format sample,
  and professor-provided/reference PDF inputs used for feedback review.
- `forms_and_admin/` (4 files): Hanyang thesis submission, midterm
  presentation, and degree-claim administrative files connected to this thesis.
- `presentation_samples/` (4 files): downloaded presentation examples actually
  referenced by the repository scripts (`양재영_중간발표_1203.pptx` and the
  three HUSA samples named in `scripts/build_pptx_husa.py`).
- `reference_papers/` (1 file): downloaded PDF thesis directly related to
  mart/retail facility effects on apartment prices.
- `thesis_presentation_20260608_134813.m4a`: June 8, 2026 thesis presentation
  discussion/feedback recording. Transcribed via Mac Studio meeting-notes
  pipeline and stored as
  `review_inputs/transcripts/thesis_presentation_20260608_134813.txt`.
- `advisor_feedback/엄상용_피드백.pdf`: June 11, 2026 professor feedback PDF
  received in Downloads. The file is image-based, so text extraction is blank;
  the rendered pages were reviewed visually and summarized in
  `committee_final_revision/UMSANGYONG_FEEDBACK_RECHECK.md`.

## Included From Downloads

The following unrelated Downloads files were intentionally excluded: software
installers, bank/card statements, contracts unrelated to this thesis, mobile app
release artifacts, non-thesis videos, legal documents, church images/scans,
network screenshots, unrelated thesis PDFs, unused HUSA sample PDFs, the full
HUSA sample zip, and other personal files.

advisor-feedback DOCX working input, while the same original is preserved under
