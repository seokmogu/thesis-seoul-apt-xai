현재 원고는 제2장에 헤도닉 가격모형과 머신러닝/XAI를 모두 두고 있으나, `paper/석사학위논문_박현근.md:241` 이후의 XAI/SHAP 설명 비중이 여전히 크다. 2026-06-08 피드백은 이 지적을 반복하면서, 이론 배경은 AVM/부동산 가격 예측 선행연구 중심으로 두고 XAI/SHAP은 방법론 쪽으로 낮추라는 방향을 더 구체화했다.

판단: 반복 피드백이지만 이번에는 "AVM 중심으로 재배치"라는 구체적 수정 방향이 새로 붙었다.

현재 원고는 2026-06-03 피드백 반영 이후 표 앞 설명이 많이 추가되었다. 예를 들어 `<표 4-8>` 앞에는 SHAP값이 인과효과가 아니라 예측 기여도라는 설명이 들어가 있다(`paper/석사학위논문_박현근.md:620`-`622`).

판단: 기존 피드백의 반복/강화다. 형식상 표 앞 문장은 들어갔지만, 심사자 관점에서는 해석량이 아직 부족하다.

### 3. 데이터 구축과 변수 설명을 더 분명히 하라는 지적

2026-06-01 피드백에는 데이터 수집, 변수 정의, 주석/부연 설명의 위치를 더 명확히 하라는 요구가 있었다. 2026-06-03 피드백도 주석을 본문 설명으로 이동하고 전문용어 설명을 보강하라는 쪽이었다.

## 새롭거나 더 강해진 항목

### 1. 논문의 차별성 재정의

2026-06-03 피드백은 제목, 주요어, 문체, 표 설명 등 형식 수정이 중심이었다. 2026-06-08 피드백은 연구 차별성 자체를 다시 좁히라고 한다.

현재 원고는 거리 기반 접근성, 시점 정합, 권역×연도 SHAP 분해를 결합한 점을 의의로 제시한다(`paper/석사학위논문_박현근.md:89`, `119`, `928`). 그러나 발표 피드백은 `머신러닝 적용`, `좌표 기반`, `실제 거리`, `GIS적 접근`이 이미 선행연구에 있으므로 그 자체를 신규성으로 내세우지 말라는 취지다.

- 차별성은 "연도별 시점 정합", "시장 국면 변화에 따른 예측 안정성", "AVM 갱신 필요성"으로 좁힌다.

판단: 새롭고 중요하다. 단순 문체 수정이 아니라 1장/초록/결론의 핵심 메시지를 바꿔야 한다.

### 3. `연도×권역 교차 SHAP` 표현 위험

현재 원고는 `연도×권역 교차 SHAP 분석`을 목차와 본문 여러 곳에서 사용한다(`paper/석사학위논문_박현근.md:35`, `143`, `470`, `749`, `819`, `835`).

2026-06-08 피드백은 `교차 분석`이라는 표현이 교차항 또는 interaction effect 분석처럼 읽힐 수 있다고 본다. 현재 수행한 것은 별도 상호작용항 검정이 아니라 연도별/권역별 결과를 비교한 것이다.

수정 방향:
- `연도×권역 교차 SHAP 분석` -> `연도별·권역별 SHAP 비교분석`
- `시공간 이질성의 실증` -> `시장 국면별 예측 기여 구조 비교`
- `권역×연도 예측 기여 구조의 이질성` -> `권역과 연도에 따라 예측 기여 구조가 달라지는 양상`

판단: 새 피드백이다. 제목, 목차, 초록, 결론까지 일괄 수정해야 한다.

### 4. AVM 갱신 주기/모델 노후화 관점

현재 원고는 AVM 실무 적용을 언급한다(`paper/석사학위논문_박현근.md:109`, `337`, `819`, `837`, `847`). 그러나 대부분 "권역별·연도별 SHAP 점검", "단지 분할 성능 주의", "신규 단지 일반화 한계" 수준이다.

현재 원고의 분석은 시간순 분할(2019~2023 학습, 2024~2025 테스트)과 연도별 같은 해 모형 비교에 가깝다(`paper/석사학위논문_박현근.md:404`, `711`-`747`). 연도별 모델 노후화 실험은 아직 없다.

판단: 새롭고 가장 큰 추가 분석 후보다. 시간이 부족하면 본문에서 과도하게 주장하지 않고, 결론/향후 연구로 낮춰야 한다. 시간이 있으면 `train year N -> test future years` 또는 `train through N -> test N+1/N+2` 실험을 추가하는 것이 가장 강하다.

3. 데이터 수집-단지 좌표-행정동 매칭-연도별 스냅샷 흐름을 더 독자 친화적으로 설명한다.
4. XAI/SHAP 이론 설명은 줄이고, AVM/부동산 가격 예측 선행연구와 연결한다.
5. 초록은 수치 나열보다 "오래된 AVM 모델을 그대로 쓰면 시장 국면 변화에서 성능과 해석이 흔들릴 수 있다"는 메시지를 중심으로 바꾼다.

### 추가 분석 여부 판단

가장 강한 추가 분석은 모델 노후화 실험이다.

후보:
- 2019년 학습 -> 2020~2025년 테스트
- 2019~2020년 학습 -> 2021~2025년 테스트
- 2019~2021년 학습 -> 2022~2025년 테스트
- 이런 식으로 학습 시점이 오래될수록 R²/RMSE/MAE가 어떻게 변하는지 확인

이 분석을 추가하면 2026-06-08 피드백의 핵심인 AVM 갱신 필요성을 가장 직접적으로 받을 수 있다. 다만 시간이 부족하면 현재 원고 안에서는 "본 연구는 갱신 주기를 직접 추정하지는 않았고, 시간순 분할 및 연도별 성능 차이를 통해 지속 검증의 필요성을 시사한다"로 낮춰 쓰는 편이 안전하다.

## 최종 판단

2026-06-08 피드백은 기존 피드백과 약 40%는 반복, 60%는 새 방향 수정으로 본다.

반복 항목:
- 이론 배경 정렬
- 표/그림 전후 설명
- 데이터 구축 설명
- 결과 해석 부족

새 항목:
- `시공간 이질성` 용어 축소
- `교차 분석` 표현 축소
- 차별성을 AVM 시점 정합/갱신 문제로 좁히기
- SHAP 수치 비교의 해석 수위 조절
- 강남3구/비강남 구분의 한계 명시
- 초록과 결론을 기술 요약이 아니라 실무 메시지 중심으로 재작성

따라서 다음 수정은 문장 다듬기보다 논문 메시지 재정렬이 먼저다. 특히 제목, 초록, 연구목적, 차별성, 제4장 제7절 제목, 결론을 한 번에 같은 방향으로 바꾸지 않으면 새 피드백이 충분히 반영됐다고 보기 어렵다.
