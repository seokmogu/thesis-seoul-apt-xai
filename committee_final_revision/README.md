## 수정 원칙

1. 제목, 초록, 연구목적, 차별성, 결론의 메시지를 먼저 맞춘다.
2. `시공간 이질성`, `연도×권역 교차 SHAP 분석`처럼 방법보다 강한 표현은 낮춘다.
3. `머신러닝`, `SHAP`, `좌표/거리 기반` 자체를 신규성으로 내세우지 않는다.
4. 핵심 메시지는 시점 정합, 시장 국면별 예측 안정성, AVM 운용 시 지속 검증 필요성으로 정렬한다.
5. 과거 학습창 기반 보조 검증은 AVM 갱신 주기 산정이 아니라 성능 재검증 필요성의 근거로만 해석한다.
6. 수정 후 DOCX/PDF 산출물이 필요하면 이 폴더의 원고를 기준으로 Windows 환경에서 생성한다.
