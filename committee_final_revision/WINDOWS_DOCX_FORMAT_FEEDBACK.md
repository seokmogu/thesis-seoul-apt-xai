## 목적

이 문서는 조미정 교수 자필 피드백 중 Windows Word에서 처리해야 하는 문서 포맷 항목만 분리한 작업 체크리스트이다.

본문 내용 보강은 Markdown 원고에 이미 반영된 항목과 구분한다. 여기서는 표, 그림, 캡션, 목차, 페이지 흐름, Word 변환 상태만 확인한다.

## Word 포맷 기본 원칙

1. 제목이나 절 제목 바로 아래에 표 또는 그림이 먼저 나오면 안 된다.
2. 제목 아래에는 최소한 해당 표/그림을 왜 보는지 설명하는 본문 문단이 먼저 나와야 한다.
3. 표 또는 그림은 가능한 한 관련 설명 문단 뒤, 페이지 하단 또는 문단 흐름의 마지막에 배치한다.
4. 표/그림 다음에는 해석 문단이 자연스럽게 이어져야 하며, 표/그림만 페이지 상단에 떠 있으면 안 된다.
5. 표와 캡션, 그림과 캡션은 서로 다른 페이지로 갈라지지 않게 한다.
6. Word에서 자동 배치 때문에 표가 문단보다 먼저 올라가면 수동 페이지 나눔 또는 문단 옵션으로 조정한다.

권장 흐름:

```text
절 제목
설명 문단
표/그림 캡션
표/그림
해석 문단
```

또는 페이지 흐름상 표/그림을 하단으로 내려야 할 때:

```text
절 제목
설명 문단
해석을 여는 문장
표/그림 캡션
표/그림
다음 문단
```

## 그림 검수 대상

자필 피드백은 주로 표를 가리키지만, Word 산출물에서는 그림도 같은 배치 원칙으로 확인한다.

| 대상 | 확인 사항 |
|---|---|
| `<그림 4-1>` 소거분석 시나리오별 XGBoost R2 비교 | `<표 4-7>` 해석 뒤에 자연스럽게 이어지는지 확인 |
| `<그림 4-8>` 권역별 SHAP 상위 5개 변수 비교 | `<표 4-10>` 및 권역별 해석과 같은 흐름에 있는지 확인 |
| `<그림 4-9>` 연도별·권역 XGBoost R2 히트맵 | `<표 4-14>`와 다른 페이지로 갈라져도 해석 문단이 끊기지 않는지 확인 |
| `<그림 4-10>` 연도별 최상위 SHAP 변수 변화 | `<표 4-16>` 및 비강남/강남 비교 해석 뒤에 배치되는지 확인 |

그림은 Word에서 `텍스트 줄 안` 배치를 우선 사용한다. `사각형`, `빽빽하게`, `앞으로` 같은 떠 있는 배치는 캡션과 본문 순서를 틀어지게 할 수 있으므로 피한다.

## Windows Word 작업 순서

1. 최종 Markdown 기준 DOCX를 열거나 Windows에서 새 DOCX로 반영한다.
2. `Ctrl + A` 후 글꼴, 줄간격, 문단 간격이 학교 양식과 맞는지 확인한다.
3. 표 목차와 그림 목차를 먼저 전체 업데이트한다.
4. 본문에서 `<표 3-2>` 추가 이후 표 번호가 끝까지 밀리지 않았는지 확인한다.
5. 위 우선 검수 대상 표를 하나씩 찾아 제목, 설명 문단, 표, 해석 문단 순서로 정렬한다.
6. 표가 페이지 상단에 단독으로 올라가면 표 앞의 설명 문단 일부를 함께 넘기거나 표를 하단으로 내린다.
7. 표가 두 페이지로 갈라지면 Word `표 속성 > 행 > 페이지 끝에서 행을 나눔 허용` 상태를 검토한다.
8. 큰 표를 한 페이지에 넣기 어렵다면 글자 크기, 셀 여백, 표 폭을 먼저 조정하고, 의미가 바뀌는 행/열 축약은 하지 않는다.
9. 그림은 `텍스트 줄 안`으로 두고, 캡션이 같은 페이지에 붙어 있는지 확인한다.
10. 수식이 Word 수식(OMML) 또는 읽을 수 있는 텍스트로 변환됐는지 확인한다.
11. 목차, 표 목차, 그림 목차를 다시 전체 업데이트한다.
12. PDF로 내보낸 뒤 표/그림 잘림, 빈 페이지, 제목 아래 표 단독 배치가 없는지 최종 확인한다.

## Word 기능 사용 가이드

- 표/그림 위치가 계속 밀리면 수동 페이지 나눔을 사용하되, 최종 PDF 확인 전까지 과도하게 넣지 않는다.
- 제목이 페이지 맨 아래에 홀로 남으면 제목 문단에 `다음 단락과 함께`를 적용한다.
- 표 캡션이 표와 분리되면 캡션 문단과 표 위치를 함께 조정한다.
- 큰 그림은 폭을 본문 폭 안에 맞추고, 캡션은 그림 바로 아래에 둔다.
- 자동 번호가 깨지면 캡션을 수동 입력하지 말고 Word의 `참조 > 캡션 삽입` 또는 기존 캡션 필드를 갱신한다.

- 본문 내용 수정 여부는 `JOMIJEONG_TEXT_FEEDBACK_RECHECK.md`와 `REVISION_LOG.md`를 기준으로 확인한다.
