# 문체·서식 추가 리뷰 기록

작성일: 2026-05-27

## 검토 관점

- 한양대학교 학위논문 제출 안내 형식과 기존 변환 스크립트의 한양대 워드 기준을 우선 적용하였다.
- 지도교수 피드백을 확장하여, AI 작성처럼 보이는 강조·약어·영어식 플롯명·근거 없는 단정 표현을 추가 점검하였다.
- 연구 방법 관련 피드백은 단순 문장 교정이 아니라 종속변수, 설명변수, 행정동 표본 범위, 시설 시점 정합의 논리 일관성 관점에서 다시 확인하였다.

## 추가 수정

- 그림 목차와 본문 캡션의 `SHAP Bar Plot`, `SHAP Summary Plot`, `SHAP Dependence Plot`을 `SHAP 변수 중요도`, `SHAP 요약도`, `SHAP 의존도` 중심 표현으로 수정하였다.
- 본문 표면 문구의 `베이스라인`, `랜덤 샘플링`, `stock 정보`, `Global Explanation`, `Local Explanation`을 각각 `기준 모형`, `무작위 표본추출`, `월별 수준값 정보`, `전체 수준 해석`, `개별 예측 해석`으로 정리하였다.
- `그림 4-10`은 2025년 라벨이 오른쪽에 붙어 보이는 문제가 있어 축 여백, 라벨 줄바꿈, 클리핑 설정을 수정하고 그림을 재생성하였다.
- 표 캡션은 굵은 글씨 없이 일반 폰트로 내보내되, 표 목차 페이지 번호가 생성되도록 DOCX 변환 스크립트의 캡션 인식식을 보정하였다.

## 서식·레이아웃 검증

- 최종 DOCX: `paper/석사학위논문_박현근.docx`
- PDF: 제출 기준이 아니며 기본 생성 경로에서 제외함
- 렌더링 확인 폴더: `paper/render_check_20260527_toc_fix`
- 렌더링 페이지 수: 87쪽
- 표지·제출서·인준서의 6pt 고정 압축 줄간격을 제거하고, 표지용 빈 줄 리듬을 복원함
- 제출서는 항목 수가 많아 제목 블록을 표지보다 작게 조정했으며, `박현근` 성명이 두 번째 표지 안에 포함됨을 확인함
- 목차·표목차·그림목차의 `PAGEREF` 필드를 정적 페이지 번호로 고정하여 `0` 표시 문제를 복구함
- 표 목차: <표 3-1>부터 <표 4-14>까지 페이지 번호 표시 확인
- 그림 목차: <그림 2-1>부터 <그림 4-10>까지 페이지 번호 표시 확인
- 큰 하단 공백 탐지: 표지·제출서 성격의 앞쪽 2쪽만 탐지되었고, 본문 장·절·그림·표가 한 줄만 남아 다음 페이지로 넘어가는 문제는 확인되지 않았다.

## 잔존 허용 표현

- `Partial Dependence Plot`, `SHAP`, `XGBoost`, `Random Forest`, `OLS` 등은 방법론 고유명사이므로 첫 정의 또는 표준 기술어로 유지하였다.
- `스냅샷`은 시점별 시설 상태 자료를 뜻하는 방법론 용어로 사용하되, 가격 인과효과가 아니라 시간 정합 장치라는 설명을 함께 둔다.
