# 석사학위논문 docx → hwp 변환 가이드 (Mac, 한컴 라이선스 없음)

## 결론 (TL;DR)
**자동 변환 불가**. hwp는 한컴 독점 바이너리 포맷이라 오프라인 도구로 만들 수 없음.
5분 GUI 작업으로 끝나는 **한컴독스 웹**이 가장 빠름.

## 옵션 비교

| 옵션 | 비용 | 소요시간 | Mac 지원 | 비고 |
|---|---|---|---|---|
| **A. 한컴독스 웹** ⭐ | 무료 가입 | 5분 | 브라우저 | 무료 1GB 업로드, hwp/pdf/docx 다운로드 가능 |
| B. 폴라리스 오피스 웹 | 무료 가입 | 5분 | 브라우저 | hwp 편집·저장 지원. 한컴 아니라 호환성 시각 점검 필요 |
| C. 한컴 한글 Mac 정품 | 유료 (~9만원) | 30분 설치 | macOS Sonoma 이상 | 영구 사용. 표지/제출서/인준서/서약서 양식 같이 다룸에 최강 |
| D. 한컴 한글 Mac 체험판 | 무료 30일 | 30분 설치 | macOS Sonoma 이상 | 한컴 회원가입 + 체험판 신청. 졸업 직전 1회용으로 충분 |
| E. Windows VM + 한컴 | VM 비용 + 라이선스 | 2시간+ | Parallels/UTM/VMware | 무거움. 다른 용도로도 Windows 필요시만 |

## 권장 경로: 한컴독스 웹 (옵션 A)

### Step 1. 가입
1. 브라우저로 `https://www.hancomdocs.com/ko` 접속
2. **회원가입** (이메일 또는 카카오·네이버 SSO)
3. 무료 요금제 자동 부여 (별도 결제 단계 없음)

### Step 2. docx 업로드 + hwp 저장
1. 가입 후 **내 저장소** 화면
2. **업로드** 버튼 → `석사학위논문_박현근.docx` 선택 (약 5.3MB, 1GB 한도 내)
3. 업로드 완료된 파일 더블클릭 → 한컴독스 편집기에서 열림
4. 상단 메뉴: **파일 → 다른 이름으로 저장** 또는 **다운로드**
5. 포맷 선택: **hwp**
6. 다운로드한 hwp 파일을 본인 Mac에 저장

### Step 3. 시각 점검 (한컴독스 편집기 안에서)
- 폰트 KoPubWorld 바탕체 정상 적용됐는지 (한컴독스 서버에 KoPubWorld 폰트 없을 가능성 — 그땐 한컴 기본 "함초롬바탕" 등으로 fallback)
- 표지/제출서/인준서 별도 페이지 분리 OK
- 표 13개, 그림 13개 모두 정상 렌더링
- 페이지 번호 i, ii, iii.../1, 2, 3... 분리 정상

### Step 4. 표지·제출서·인준서·서약서
- 학교 양식 hwp 파일들 (`templates/학위논문체제,형식(한글).hwp` 등)을 한컴독스에서 동일하게 열어 채움
- 본문 hwp 뒤에 이어 붙이거나, 인쇄 단계에서 통합

## 주의사항
- 한컴독스 서버 한글 폰트 한도: KoPubWorld 바탕체 미설치 가능성 → 변환 후 폰트 매핑 확인 필수
- 만약 표·그림 깨짐 발생: docx 원본 다시 열어 한컴독스에서 부분 재편집
- 백업: `paper/backup/` 폴더에 변환 직전 docx/pdf 보관됨

## 대안 — PDF 제출 검토
한양대 일반대학원 가이드 §4-1 ②: **"등록 가능 파일 형식: PDF(텍스트), HWP, DOC"** → PDF도 공식 허용.
만약 학과/지도교수에서 hwp 강제가 아니라면 **현재 docx로 만든 PDF 그대로 dCollection 업로드** 가능.
재확인 후 hwp 변환이 불필요할 수도 있음.
