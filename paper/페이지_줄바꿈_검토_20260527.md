# 페이지별 줄바꿈 검토 기록

작성일: 2026-05-27

## 수정 사항

- 표지에서 `박현근` 이름만 다음 페이지로 밀릴 수 있는 원인은 표지·제출서의 빈 줄 높이가 Word/한컴에서 크게 계산될 가능성으로 판단하였다.
- 1차 조정에서 빈 줄을 6pt 고정 높이로 줄였으나, 표지 양식의 세로 리듬이 과도하게 압축되는 문제가 확인되어 폐기하였다.
- `scripts/export_docx_v8.py`, `scripts/export_docx_v8_compact.py`에서 표지·제출서·인준서의 빈 줄을 1줄 기준으로 복원하고, 중앙 정렬 문단은 1.15배 줄간격으로 재설정하였다.
- 표지는 기존 한양대 양식의 빈 줄 구조를 기준으로 위쪽 2줄, 학위명 뒤 1줄, 한영 제목 사이 1줄, 이름 앞 3줄, 학교명 앞 2줄, 날짜 앞 1줄로 조정하여 전체가 한 페이지에 안정적으로 들어오도록 수정하였다.
- 제출서는 표지보다 항목이 많아 동일 제목 크기를 적용하면 `박현근` 성명이 다음 페이지로 밀릴 수 있으므로, 제출서 제목 블록만 한 단계 축소하고 긴 영문 부제 줄을 10pt로 조정하였다.
- PDF 기본 생성을 끄면서 목차 `PAGEREF` 번호가 `0`으로 남는 문제가 확인되어, 최종 PDF를 남기지 않는 임시 렌더 방식으로 목차 페이지 번호 55개를 정적 텍스트로 고정하도록 복구하였다.
- 결론 마지막 후속 연구 문단이 3줄만 다음 페이지에 고립되는 문제가 있어 문단을 압축하였다.

## 렌더링 검증

- 최종 DOCX: `paper/석사학위논문_박현근.docx`
- PDF: 제출 기준이 아니므로 기본 생성 경로에서 제외함
- 렌더링 확인 폴더: `paper/render_check_20260527_toc_fix`
- 총 페이지 수: 87쪽
- 표지 1쪽: `박현근` 이름이 표지 안에 포함되고, 제목·영문제목·이름·학교명·날짜 사이 간격이 과도하게 붙지 않음
- 제출서 2쪽: 지도교수, 제출 문구, 전공, 성명 모두 한 페이지 안에 포함되고, `박현근` 성명이 같은 페이지 하단에 유지됨
- 인준서 3쪽: 인준 문구와 심사위원 서명란이 한 페이지 안에 포함됨
- 목차 4쪽: 목차 페이지 번호가 `0`이 아니라 본문 쪽수로 표시됨
- 본문 4쪽 이후: 4줄 이하로 홀로 남은 페이지 없음
- 제목·표 캡션·그림 캡션이 페이지 하단에 단독으로 걸린 본문 페이지 없음
- 큰 하단 공백은 표지·제출서·인준서 3쪽에서만 확인되며, 이는 양식 페이지 성격상 허용되는 공백으로 판단하였다.

## 실행 검증

- `scripts/export_docx_v8.py` 실행 완료
- `scripts/export_docx_v8_compact.py` 실행 완료

- DOCX 본문 OOXML에서 `lineRule="exact"` 고정 줄간격 문단 0건 확인
- DOCX 내부 `PAGEREF` 목차 필드 0건 확인
- `small_pages_after_front=[]` 확인
