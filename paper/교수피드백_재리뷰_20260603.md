# 교수 피드백 재리뷰 (2026-06-03)

검토 대상: `paper/석사학위논문_박현근.md`

## 결론

2026-06-03 Word 메모에서 확인된 직접 이슈는 현재 원문과 산출물 기준으로 해소되었다. 특히 제목, 인용 표기, 구현 변수명 노출, 주석형 설명, 표 번호 포함 소제목, 콜론형 나열 문장은 원고·DOCX XML·PDF 텍스트 검증 기준으로 제거되었다.

## 확인 항목

1. 제목
   - 국문 제목에서 교수 메모가 지적한 `단위면적당` 표현을 삭제하였다.
   - 영문 제목에서도 대응 표현인 `Unit-Area`를 삭제하였다.
   - 영문 제목은 국문 제목의 의미와 정합된다.
   - DOCX 표지와 제출서 생성 스크립트의 하드코딩 제목도 함께 수정하였다.

2. 주요어
   - 도구명 중심 주요어를 제거하고 연구 대상·방법론적 관점 중심으로 수정하였다.

3. 인용 표기
   - `Lundberg와`, `Choy와`, `et al.(` 패턴은 남아 있지 않다.
   - 외국 저자 2인 이상 표기는 교수 피드백에 맞춰 `&` 형식으로 정리하였다.

4. 근거와 개념 설명
   - 도로 우회 보정계수는 실측 상수로 주장하지 않고 한계와 함께 설명하였다.
   - 새로 추가한 Boeing (2019)은 PDF를 직접 다운로드해 `references/papers/`에 보관하였다.

5. 표와 본문 설명
   - 표 번호가 들어간 소제목 패턴 `(<표 4-`은 남아 있지 않다.
   - 주요 결과표 앞에 표의 목적 또는 해석 문단이 추가되었다.

6. 문체
   - `전체 수준 해석:`, `결정계수 (R²):` 같은 정의 카드형 문장은 제거되었다.
   - 지적된 유형과 같은 문제를 XGBoost 특징, XAI 필요성, 평가 지표, 연구 기여 문단까지 확장 수정하였다.

## 잔여 이슈

1. 목차와 표 목차에는 표 번호가 남아 있다. 이는 본문 소제목 문제가 아니라 논문 형식상 표 목차/표 제목이므로 유지하는 것이 맞다.
2. `1.35` 보정계수는 다운로드 가능한 문헌으로 직접 입증하지 않았으므로, 본문은 해당 값을 휴리스틱으로 제한했고 Boeing (2019)은 circuity 개념 근거로만 인용했다.
3. Word에서 목차 필드는 열 때 업데이트가 필요할 수 있다. 이는 export 스크립트의 기존 DOCX 제출용 동작이다.
