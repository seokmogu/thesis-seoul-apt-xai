# 연구윤리 서약서 (별도 출력·첨부)

본 학위논문 인쇄·제본 시 다음 2개 페이지를 **본 docx 뒤에 별도 첨부**한다.

## 출력 방법
HY-in(`https://hyin.hanyang.ac.kr`) → 신청 → 논문 → **논문심사결과보고서** 화면에서 출력.
- 연구윤리서약서(국문) 1매
- 연구윤리서약서(영문) 1매

두 장은 결과보고서와 함께 자동 출력된다 (FAQ Q10).

## 제출 처리
- **원본**(서명 또는 인쇄된 서명 포함)을 소속 단과대학 행정팀에 제출
- 본인 보관용 **복사본 1부**를 본문 인쇄본 끝(ABSTRACT·감사의 글 뒤)에 끼워 제본

## 제본 순서상 위치 (가이드 §2)
```
... → ⑩ ABSTRACT → ⑪ 감사의 글 → ⑫ 연구윤리서약서(국문) → ⑬ 연구윤리서약서(영문)
```

## 주의
- 서명 또는 도장 날인 필수
- 제출 직전 학위수여년월(예: 2026년 8월)에 맞게 HY-in 정보 갱신 후 출력
